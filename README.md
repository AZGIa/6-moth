# 182 дня — автономная версия

Приложение для шестимесячного челленджа: английский, калистеника, стойка на руках, йога, бег.
Работает полностью офлайн, ничего не требует от интернета после первой загрузки,
никакой связи с Claude или любым другим сервисом.

## Что в архиве

```
index.html            страница
styles.css            стили
app.js                вся логика
plan.js               программа на 182 дня (данные)
words.js              1608 английских слов с переводами (данные)
sw.js                 service worker — то, что даёт офлайн
manifest.webmanifest  описание приложения для «На экран Домой»
icon-180.png          иконка для айфона
icon-192.png          иконка
icon-512.png          иконка
```

Ничего не собирается и не компилируется. Все 11 файлов лежат одной кучей,
без вложенных папок — так их можно выделить разом при загрузке с телефона.
Класть их надо тоже в одну папку, рядом друг с другом.

## Важно: почему нельзя просто открыть файл

На айфоне открыть `index.html` из «Файлов» не получится — точнее, откроется,
но работать не будет. Safari даёт таким страницам адрес `file://`, а для него
не работают ни «На экран Домой», ни надёжное хранилище: данные могут пропасть
в любой момент. Это ограничение iOS.

Поэтому файлы нужно разместить на хостинге, и обязательно **по HTTPS**.
Service worker (офлайн-режим) на обычном `http://` не запускается — браузеры
разрешают его только на HTTPS и на `localhost`.

На макбуке файл откроется и локально, но данные будут отдельные от телефонной
версии, так что смысла в этом мало.

## Куда разместить

Подойдёт любой хостинг статики с HTTPS. Три варианта по убыванию надёжности
для России:

**Свой хостинг или VPS.** Timeweb, reg.ru, любой другой. Точно откроется без VPN
и не отключится завтра. Загружаешь папку по FTP или SFTP в корень сайта —
дальше как с твоим фронтом для 1С, разница только в том, что здесь ещё нужен
валидный сертификат (у большинства хостингов Let's Encrypt включается в панели
одной кнопкой).

**GitHub Pages.** Бесплатно, HTTPS из коробки. Создаёшь репозиторий, кладёшь
туда файлы, в настройках репозитория Pages → Source → ветка `main`, папка `/`.
Через минуту сайт живёт по адресу `https://<логин>.github.io/<репозиторий>/`.

**Netlify или Cloudflare Pages.** Бесплатно, разворачивается перетаскиванием
папки в окно браузера, адрес выдаётся сразу.

Проверь заранее, что выбранный вариант открывается у тебя без VPN — я отсюда
этого проверить не могу.

## Установка на устройства

**iPhone.** Открой адрес в Safari (именно в Safari, не в Chrome — в других
браузерах на iOS установка не работает). Кнопка «Поделиться» → «На экран
"Домой"». Появится иконка, приложение будет запускаться на весь экран без
адресной строки.

**MacBook.** Safari → меню «Файл» → «Добавить в Dock». В Chrome — иконка
установки справа в адресной строке.

После установки один раз открой приложение при работающем интернете — оно
запишет себя на устройство целиком. Дальше сеть не нужна вообще: в метро,
в подвале, в самолёте, с выключенным Wi-Fi — открывается и работает.

## Данные

Всё хранится прямо на устройстве, в хранилище браузера. Каждое устройство —
само по себе: отметки с айфона не появятся на макбуке автоматически.

Переносить вручную: **Гид → Настройки**.

- **Выгрузить в файл** — сохраняет весь прогресс в `.json`. На айфоне выбери
  «Сохранить в Файлы» → iCloud Drive, тогда файл сам окажется на всех устройствах.
- **Загрузить и объединить** — берёт файл и складывает с тем, что уже есть.
  Ничего не стирает: галочки объединяются, по каждому слову берётся лучший
  прогресс, замеры дописываются. Это то, что нужно в 99% случаев.
- **Заменить всё** — стирает текущее и ставит из файла. Только для отката
  к сохранённой копии.

**Выгружай файл раз в неделю, даже если не переносишь данные.** Это резервная
копия. Если очистить историю и данные сайтов в Safari, прогресс приложения
удалится вместе с ними — восстановить будет неоткуда.

## Обновление

Если правишь файлы, обязательно подними версию в `sw.js`, первая строка:

```js
var VERSION = "182dnya-v1";   →   var VERSION = "182dnya-v2";
```

Без этого устройства продолжат показывать старую версию из кэша — они
специально так устроены, чтобы работать офлайн. После смены версии приложение
обновится при следующем открытии само.

## Если понадобится синхронизация

Автоматическая синхронизация между устройствами требует сервера в интернете —
без него телефон и макбук физически не смогут узнать об изменениях друг друга.
Когда захочешь, это добавляется поверх текущей версии: два вебхука в n8n
(чтение и запись) на внешнем VPS, либо Supabase с бесплатным тарифом.
Трогать придётся только `app.js` — остальное останется как есть.
